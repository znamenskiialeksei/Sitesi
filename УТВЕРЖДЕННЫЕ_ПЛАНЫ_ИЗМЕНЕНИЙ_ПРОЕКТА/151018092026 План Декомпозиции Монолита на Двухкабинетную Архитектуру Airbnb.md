- **Дата утверждения:** 18.09.2026 15:10
- **Статус:** ✅ Успешно реализовано
- **Ключевой модуль:** Архитектура проекта / Витрина + Кабинет гостя + Кабинет хозяина + Командный граф C&C

---

## 1. Цель и контекст задачи
Исходный монолитный файл `pages/index.js` содержал 1474 строки спагетти-кода, где личные кабинеты гостя и хозяина переключались через флаг `currentUser?.isHost`, а уведомления отображались через блокирующие браузерные `alert()`.
Требовалось:
1. Выполнить полную архитектурную декомпозицию приложения на модули в стиле Airbnb.
2. Изолировать Личный кабинет путешественника (`pages/guest/index.js` + `components/GuestCabinet/`).
3. Изолировать Центр управления суперхозяина (`pages/host/index.js` + `components/HostCabinet/`).
4. Разработать визуальный командный граф C&C (`pages/host/graph.js`).
5. Внедрить глобальный контекст авторизации и неблокирующие всплывающие тосты.

## 3. Архитектурные решения
1. **Декомпозиция на 3 независимых маршрута:**
   - Публичная витрина листинга доступна всем посетителям без авторизации.
   - Личный кабинет гостя изолирован по URL `/guest` и требует базовой гостевой авторизации.
   - Центр управления хозяина изолирован по URL `/host` и защищен Google Authenticator 2FA (TOTP) с выпуском сессионного токена.
2. **Ликвидация спагетти-кода:**
   - Компоненты кабинета гостя вынесены в `components/GuestCabinet/` (`GuestBookings.js`, `GuestChat.js`, `GuestGuides.js`, `GuestProfile.js`).
   - Компоненты кабинета хозяина вынесены в `components/HostCabinet/` (`HostReservations.js`, `HostCalendar.js`, `HostInbox.js`, `HostSettings.js`, `HostChannelManager.js`).
3. **Стандарт комментирования кода:**
   - 100% файлов снабжены исчерпывающими русскоязычными комментариями к каждой секции.
