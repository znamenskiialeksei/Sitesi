## 3. Ключевые фрагменты кода
```javascript
// Правило округления в большую сторону до кратного 5 без центов/копеек
export function roundToFive(amount) {
  const num = Number(amount) || 0;
  return Math.ceil(num / 5) * 5;
}
```
