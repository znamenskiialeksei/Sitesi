# ИНСТРУКЦИЯ ПО НАСТРОЙКЕ РАСШИРЕНИЯ GOOGLE APPS SCRIPT И СВОЙСТВ СКРИПТА

## 1. Как встроить скрипт в расширение Google Таблицы:
1. Откройте вашу Google Таблицу в браузере.
2. В верхнем меню выберите: `Расширения` ➔ `Apps Script`.
3. В открывшемся редакторе кода полностью удалите весь существующий текст.
4. Скопируйте и вставьте полное содержимое файла `google-apps-script/Code.js`.
5. Нажмите кнопку «Сохранить проект»: иконка дискеты или клавиши `Ctrl+S`.
6. Перезагрузите страницу с вашей Google Таблицей в браузере: клавиша `F5`.
7. Через несколько секунд в верхней панели появятся два главных меню:
   - **`🏡 Villa Turaman Suite`**: управление 14 листами, пресетами, каталогом, ревалидацией и свойствами.
   - **`🤖 Telegram Бот`**: мобильный центр управления хозяина, модерация заявок, чаты и webhook.

---

## 2. Структура второго главного меню: 🤖 Telegram Бот:

Второе главное меню верхнего уровня **`🤖 Telegram Бот`** содержит 6 функциональных блоков:
1. **`📲 1. Запуск и Меню бота`**:
   - Отправить Главное меню на телефон хозяина
   - Обновить клавиатуру бота: постоянный Reply Keyboard с 6 кнопками
   - Зарегистрировать команды в Telegram: `setMyCommands`
2. **`📋 2. Заявки и Бронирования`**:
   - Отправить список активных заявок в Telegram с кнопками: Одобрить 24ч HOLD, Отклонить, Ответить
   - Аудит накладок и 24ч HOLD в Telegram
3. **`💬 3. CRM и Переписка с гостями`**:
   - Отправить сводку последних диалогов в Telegram с кнопками быстрого ответа
   - Отправить сообщение гостю через Telegram
   - Массовая рассылка гостям через Telegram
4. **`📅 4. Календарь и Тарифы`**:
   - Отправить график занятости виллы на 30 дней
   - Отправить сводку актуальных тарифов
5. **`🌐 5. Синхронизация с сайтом`**:
   - Вызвать ревалидацию страниц сайта через бот
   - Проверить статус доступности кабинета хозяина
6. **`⚙️ 6. Настройки Webhook и Токена`**:
   - Установить Webhook на сайт: Next.js API `/api/telegram-webhook`
   - Проверить статус Webhook: `getWebhookInfo`
   - Удалить Webhook: переход на Polling
   - Настроить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
   - Тестовый пинг в Telegram

## 3. Размещение ключей в экосистеме: Vercel, Script Properties, env:

Для полноценной и бесперебойной работы платформы все переменные окружения и секретные ключи могут размещаться как на облачном хостинге **https://vercel.com/**, так и в **Script Properties** Google Таблицы и локальном файле `.env.local`.

### Уровень 1: Облачный хостинг https://vercel.com/ :Production и Preview:
На хостинге Vercel хранятся ключи доступа, используемые Next.js сервером для защищенного обращения к Google Sheets API, Telegram Bot API и KV базе данных:
1. Перейдите в личный кабинет на **https://vercel.com/**.
2. Выберите ваш проект платформы: например `sitesi`.
3. Откройте вкладку: **Settings** ➔ **Environment Variables**.
4. Добавьте необходимые переменные окружения для окружений **Production**, **Preview**, **Development**:
   - `GOOGLE_SPREADSHEET_ID`: ID основной Google Таблицы каталога и бронирований
   - `GOOGLE_CHATS_SPREADSHEET_ID`: ID Google Таблицы чатов гостей и диалогов
   - `GOOGLE_CLIENT_EMAIL`: Email сервисного аккаунта Google Cloud IAM
   - `GOOGLE_PRIVATE_KEY`: Приватный ключ сервисного аккаунта Google Cloud IAM
   - `TELEGRAM_BOT_TOKEN`: Токен Telegram-бота от @BotFather
   - `TELEGRAM_CHAT_ID`: Числовой ID чата владельца в Telegram
   - `REVALIDATE_SECRET_TOKEN`: Секретный токен для мгновенной ревалидации страниц
   - `KV_DATABASE_URL` или `KV_REST_API_URL`: Параметры Vercel KV хранилища для чатов
5. После сохранения переменных перезапустите деплой: **Deployments** ➔ **Redeploy** для вступления ключей в силу.
6. Проверить статус ключей на Vercel прямо из Google Таблицы: **🤖 Telegram Бот** ➔ **⚙️ 6. Настройки Webhook и Токена** ➔ **🌐 Проверить статус ключей на Vercel: https://vercel.com/**.

## 4. Настройка Свойств скрипта: Script Properties в Google Apps Script:

Свойства скрипта сохраняются в защищенном хранилище Google Apps Script и используются самой таблицей для отправки вебхуков ревалидации на сайт Vercel, запуска Deploy Hook и отправки уведомлений в Telegram.

### Способ 1: Прямо через меню Google Таблицы:
1. В Google Таблице нажмите: **`🤖 Telegram Бот`** ➔ **`⚙️ 6. Настройки Webhook и Токена`** ➔ **`🔑 Настроить TELEGRAM_BOT_TOKEN и CHAT_ID`**.
2. Либо перейдите в: **`🏡 Villa Turaman Suite`** ➔ **`⚙️ 6. Системный аудит & Свойства`** ➔ **`🔑 1. Настроить Свойства скрипта`**.
3. В появившемся диалоговом окне подтвердите или введите параметры по очереди:
   - `SITE_URL`: адрес сайта, например `https://sitesi-git-v1-airbnb-znamenskiialekseis-projects.vercel.app`
   - `REVALIDATE_API_URL`: `https://.../api/revalidate`
   - `REVALIDATE_SECRET_TOKEN`: секретный ключ из файла `.env.local`
   - `VERCEL_DEPLOY_HOOK_URL`: Deploy Hook из панели Vercel: опционально
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота из `@BotFather`
   - `TELEGRAM_CHAT_ID`: ID чата владельца
4. Нажмите ОК: свойства будут моментально сохранены!

---

## 5. Подключение Webhook для двустороннего чата и модерации из Telegram:
1. Убедитесь, что `SITE_URL` сохранен в Свойствах скрипта.
2. В Google Таблице нажмите: **`🤖 Telegram Бот`** ➔ **`⚙️ 6. Настройки Webhook и Токена`** ➔ **`🔗 Установить Webhook на сайт: Next.js API`**.
3. Скрипт автоматически зарегистрирует адрес `https://<ВАШ_ДОМЕН>/api/telegram-webhook` в Telegram Bot API.
4. Нажмите **`🔍 Проверить статус Webhook: getWebhookInfo`** для подтверждения статуса соединения.

---

## 6. Автоматический триггер мгновенного обновления сайта:
Чтобы сайт автоматически обновлялся при редактировании ячеек:
1. В редакторе Apps Script слева нажмите на иконку будильника: **Триггеры**.
2. Нажмите **Добавить триггер** в правом нижнем углу.
3. Выберите параметры:
   - Выберите функцию: `sendUpdateSignal`
   - Развертывание: `Основное: Head`
   - Источник мероприятия: `Из таблицы: From spreadsheet`
   - Тип события: `При редактировании: On edit`
4. Нажмите **Сохранить** и подтвердите разрешения Google аккаунта.
