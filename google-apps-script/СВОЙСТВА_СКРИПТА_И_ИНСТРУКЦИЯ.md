# ИНСТРУКЦИЯ ПО НАСТРОЙКЕ РАСШИРЕНИЯ GOOGLE APPS SCRIPT И СВОЙСТВ СКРИПТА
# ==============================================================================

## 1. Как встроить скрипт в расширение Google Таблицы:
1. Откройте вашу Google Таблицу в браузере.
2. В верхнем меню выберите: `Расширения (Extensions)` ➔ `Apps Script`.
3. В открывшемся редакторе кода полностью удалите весь существующий текст.
4. Скопируйте и вставьте полное содержимое файла `google-apps-script/Code.js`.
5. Нажмите кнопку «Сохранить проект» (иконка дискеты `Ctrl+S`).
6. Перезагрузите страницу с вашей Google Таблицей в браузере (`F5`).
7. Через несколько секунд в верхней панели появится новое меню: **`🏡 Villa Turaman Suite`**.

---

## 2. Настройка «Свойств скрипта» (Script Properties):

Свойства скрипта сохраняются в защищенном хранилище Google Apps Script и используются для автоматической отправки вебхуков ревалидации на сайт, запуска деплоя на Vercel и отправки уведомлений в Telegram.

### Способ 1: Прямо через меню Google Таблицы (Рекомендуемый, в 1 клик):
1. В Google Таблице нажмите: **`🏡 Villa Turaman Suite`** ➔ **`⚙️ 6. Системный аудит & Свойства`** ➔ **`🔑 1. Настроить Свойства скрипта`**.
2. В появившемся диалоговом окне подтвердите или введите параметры по очереди:
   - `SITE_URL`: адрес сайта (например, `https://ваша-вилла.vercel.app` или `http://localhost:3000`)
   - `REVALIDATE_API_URL`: `https://ваша-вилла.vercel.app/api/revalidate`
   - `REVALIDATE_SECRET_TOKEN`: секретный ключ из файла `.env.local`
   - `VERCEL_DEPLOY_HOOK_URL`: Deploy Hook из панели Vercel (необязательно)
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота в Telegram
   - `TELEGRAM_CHAT_ID`: ID чата владельца
3. Нажмите ОК — свойства будут моментально сохранены!

### Способ 2: В редакторе Apps Script вручную:
1. В редакторе Apps Script нажмите слева на значок шестеренки: **«Настройки проекта» (Project Settings)**.
2. Прокрутите страницу вниз до раздела **«Свойства скрипта» (Script Properties)**.
3. Нажмите кнопку **«Добавить свойство скрипта»** и внесите пары:
   - **Свойство:** `SITE_URL` | **Значение:** `https://ваша-вилла.vercel.app`
   - **Свойство:** `REVALIDATE_API_URL` | **Значение:** `https://ваша-вилла.vercel.app/api/revalidate`
   - **Свойство:** `REVALIDATE_SECRET_TOKEN` | **Значение:** `[секретный токен из .env.local]`
   - **Свойство:** `VERCEL_DEPLOY_HOOK_URL` | **Значение:** `[deploy hook]`
   - **Свойство:** `TELEGRAM_BOT_TOKEN` | **Значение:** `[токен бота]`
   - **Свойство:** `TELEGRAM_CHAT_ID` | **Значение:** `[ID чата]`
4. Нажмите **«Сохранить свойства скрипта»**.

## 3. Автоматический триггер мгновенного обновления сайта:
Чтобы сайт автоматически обновлялся при редактировании ячеек:
1. В редакторе Apps Script слева нажмите на иконку будильника: **«Триггеры» (Triggers)**.
2. Нажмите **«Добавить триггер» (Add Trigger)** в правом нижнем углу.
3. Выберите параметры:
   - Выберите функцию: `sendUpdateSignal`
   - Развертывание: `Основное (Head)`
   - Источник мероприятия: `Из таблицы (From spreadsheet)`
   - Тип события: `При редактировании (On edit)`
4. Нажмите **«Сохранить»** и подтвердите разрешения Google аккаунта.
