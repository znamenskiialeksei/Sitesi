## 🎯 Назначение папки
Данная папка содержит полный комплект адаптированных скриптов автоматизации и управления жизненным циклом для изолированной ветки `v1-airbnb`, подготовленной к развертыванию на Vercel и автономному запуску.

## 📋 Реестр скриптов ветки v1-airbnb

### 1. `pause-site.sh`
* **Роль:** Мгновенный перевод сайта в режим технического обслуживания на Vercel.
* **Функционал:**
  - Генерирует стильную страницу-заглушку `maintenance.html` в темно-синих тонах виллы прямо в корне ветки `v1-airbnb`;
  - Создает `vercel.json` с кодом ответа HTTP 503 (защита SEO);
  - Фиксирует коммит и пушит изменения непосредственно в ветку `origin v1-airbnb`.

### 2. `resume-site.sh`
* **Роль:** Восстановление штатной работы сайта после регламентных работ.
* **Функционал:**
  - Удаляет заглушку `maintenance.html` и файл `vercel.json` через Git;
  - Отправляет коммит в ветку `origin v1-airbnb`, инициируя автоматическую повторную сборку Next.js на Vercel.

### 3. `deploy_and_run.sh`
* **Роль:** Универсальный мастер-скрипт развертывания и запуска платформы Airbnb в 1 команду.
* **Функционал:**
  - Проверяет Node.js 18+ и npm;
  - Инициализирует файловую структуру;
  - Проверяет и устанавливает зависимости (`npm install`);
  - Автоматически освобождает порт 3000;
  - Предоставляет интерактивное терминальное меню: Dev-сервер, Сборка, Старт, Синхронизация Google Sheets, CRM-инициализация, Пауза/Возобновление.

### 4. `deploy-villa-turaman.sh`
* **Роль:** Исторический монолитный скрипт полной кодогенерации платформы.

### 5. `deploy_and_run.bat`
* **Роль:** Нативный 4-строчный безопасный трамплин для Windows.
