## 🎯 Назначение папки
Данная папка содержит все исторические скрипты автоматизации и запуска, которые создавались на ранних итерациях проекта в корне рабочей области. В рамках перехода на трехуровневую архитектуру глобальных настроек (Запускатор ➔ Накопитель ➔ Проекты) и очистки корня, все исторические скрипты сохранены без изменений внутри проекта по каноническому стандарту `ЧЧммДДММГГГГ [Название на русском]` (Директивы 6 и 10).

## 📋 Реестр законсервированных скриптов

### 1. `deploy-villa-turaman.sh` (308 КБ, 4300+ строк)
* **Роль:** Исторический монолитный Bash-скрипт полного развертывания платформы Villa Turaman с нуля.
* **Функционал:**
  - Инициализирует структуру каталогов Next.js;
  - Устанавливает библиотеки (`googleapis`, `node-ical`, `stripe`, `iyzipay`, `yookassa`, `pdfkit`);
  - Генерирует все страницы, стили Tailwind CSS, компоненты бронирования;
  - Настраивает интеграции со шлюзами Stripe, ЮKassa, Т-Банк и базой данных Google Sheets;
  - Генерирует скрипты синхронизации контента и обработчики webhook.

### 2. `pause-site.sh` (~8 КБ)
* **Роль:** Автоматизированный перевод сайта в режим технического обслуживания на хостинге Vercel.
* **Функционал:**
  - Генерирует статическую страницу заглушки `maintenance.html` («Ведутся технические работы»);
  - Формирует конфигурационный файл `vercel.json` с кодом HTTP 503 (Service Unavailable) для сохранения SEO-позиций;
  - Фиксирует коммит в Git и автоматически пушит изменения в ветку `main` репозитория GitHub.

### 3. `resume-site.sh` (~2 КБ)
* **Роль:** Восстановление штатной работы сайта после технического обслуживания.
* **Функционал:**
  - Удаляет заглушку `maintenance.html` и временный `vercel.json` из репозитория и индекса Git;
  - Фиксирует коммит отмены режима обслуживания;
  - Отправляет изменения в GitHub, инициируя автоматическую повторную сборку Vercel.

### 4. `deploy_and_run.sh` (~18 КБ)
* **Роль:** Универсальный автоматизированный мастер-скрипт развертывания окружения и запуска.
* **Функционал:**
  - Проверяет Node.js, npm, Google Chrome;
  - Создает структуру каталогов (`.vscode`, `browser_profiles/vrbo`, `invoices`, `_BACKUPS`, `scratch`);
  - Развертывает задачи `.vscode/tasks.json` и профиль `.vscode/settings.json`;
  - Проверяет конфигурацию `.env`;
  - Устраняет конфликты занятых портов (Port 3000 Auto-Heal);
  - Запускает цветное интерактивное терминальное меню управления (Total Launch, Browser, Localtunnel, Diagnostics).

### 5. `deploy_and_run.bat` (~2 КБ)
* **Роль:** Нативный 1-кликовый Windows-запускатор.
* **Функционал:**
  - Автоматически находит установленный Git Bash в системе;
  - Вызывает `deploy_and_run.sh` в среде Bash;
  - При отсутствии Bash выполняет нативный аварийный сценарий на CMD.
