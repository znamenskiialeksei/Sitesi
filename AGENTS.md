### БЛОК II: СРЕДА ВЫПОЛНЕНИЯ VS CODE И POWERSHELL СТАНДАРТЫ
* **2.1. VS Code Exclusive Workspace:** Пользователь работает ИСКЛЮЧИТЕЛЬНО в программе VS Code и ее встроенном терминале. Запрещены внешние консоли. *(см. [GEMINI.md п. 2.1])*
* **2.2. Triple-Tier Launch Protocol:** Любое действие предоставляется строго в 3 форматах: 1. GUI VS Code (`Ctrl+Shift+P`, меню, `Ctrl+Shift+B`, `F5`); 2. Имя задачи из `.vscode/tasks.json`; 3. Нативная команда для встроенного PowerShell терминала. *(см. [GEMINI.md п. 2.2])*
* **2.3. PowerShell 7 (pwsh.exe) Standard:** Все задачи вызываются через `pwsh -ExecutionPolicy Bypass -File ...`. Отказ от вызова устаревшего powershell 5.1 и костылей. Привязка `[powershell]: { files.encoding: "utf8bom" }`. *(см. [GEMINI.md п. 2.3])*
* **2.4. UTF-8 BOM Signature:** Все скрипты `.ps1` создаются и сохраняются со строгой сигнатурой UTF-8 BOM (`\uFEFF`) для 100% совместимости. *(см. [GEMINI.md п. 2.4])*
* **2.5. ASCII Naming Standard:** Все исполняемые `.ps1` сценарии именуются строго латиницей snake_case для предотвращения искажений кодовых страниц Windows. *(см. [GEMINI.md п. 2.5])*
* **2.6. Total Elimination of .bat Files:** Запускаторы `.bat` (`deploy_and_run.bat`) полностью ликвидированы по требованию пользователя. Все действия только через задачи VS Code и pwsh. *(см. [GEMINI.md п. 2.6])*
* **2.7. Total Zero-Brackets & Zero-Emdash Policy:** Тотальный запрет на любые скобки и типографское длинное тире во всех строках, Write-Host, комментариях, задачах VS Code, папках и файлах. Канонический стандарт: строго ASCII-дефис `-` (код 0x2D) или двоеточие `:`. Авто-санитизация агентом. *(см. [GEMINI.md п. 2.7])*
* **2.8. Изоляция cwd в задачах VS Code:** Запрет путей со скобками в строке команды `command`. Рабочая папка изолируется в `"options": { "cwd": "..." }`, в строке передается относительное имя скрипта. *(см. [GEMINI.md п. 2.8])*
* **2.9. Direct foreach Iteration:** Полный отказ от многострочных конвейеров `Where-Object` с кириллицей. Использование детерминированных циклов `foreach`. *(см. [GEMINI.md п. 2.9])*
* **2.10. Port Conflict Management:** Автоматическая проверка и освобождение порта 3000 перед запуском Next.js сервера. *(см. [GEMINI.md п. 2.10])*
