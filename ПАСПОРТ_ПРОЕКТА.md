## РАЗДЕЛ 2. ОБЩИЕ СВЕДЕНИЯ И АРХИТЕКТУРНЫЙ СТЕК

1. **Фронтенд и клиентский рендеринг:**
   - **Next.js 14.2.35 Pages Router:** Гибридный рендеринг SSG + ISR, фоновая ревалидация контента и On-Demand Revalidation через защитный токен.
   - **React 18.2.0:** Модульная компонентная структура, декомпозиция на независимые блоки.
   - **Tailwind CSS 3.4.1:** Адаптивная мобильная и десктопная верстка, темная тема Slate со стеклянным блюром.
   - **Lucide React 1.28.0:** Библиотека векторных интерфейсных иконок.
   - **React Datepicker и Date-fns:** Календарь занятости с локализацией на RU, EN, TR.

2. **Бэкенд, облачные сервисы и безопасность:**
   - **Google Sheets API v4:** Высокопроизводительная CRM-база данных на канонических листах с динамической привязкой по sheetId, пакетной записью batchUpdate и кэшированием.
   - **ИИ-модуль Google Gemini 3.6 Flash:** Анализ интентов, динамический контекст знаний, помощь суперхозяину при ответах гостям.
   - **Google Chats Sheets:** Выделенная база персональных чатов с динамическим автосозданием вкладок диалогов.
   - **Telegram Bot API:** Двусторонний командный пункт: мгновенные оповещения, инлайн-модерация заявок [Одобрить 24ч HOLD / Отклонить], ответы в чат гостя прямо из Telegram.
   - **Vercel Serverless Architecture:** Серверные API-маршруты `/api/booking`, `/api/calendar`, `/api/ai/copilot`, `/api/ai/knowledge`, `/api/admin/verify-2fa`.

## РАЗДЕЛ 3. ИНСТРУКЦИИ ПО РАЗВЕРТЫВАНИЮ И ЗАПУСКУ

### Системные требования:
- Операционная система: Windows 10/11, Linux, macOS.
- Среда выполнения: Node.js 18.17.0+ и npm 9+.
- Редактор кода: Visual Studio Code с терминалом PowerShell 7 [pwsh.exe].

- Сборка и старт dev-сервера в VS Code: `Ctrl+Shift+B` или задача `npm run dev`.
- Платформа доступна по адресу: `http://localhost:3000`.
- Кабинет суперхозяина: `http://localhost:3000/host`.
- Кабинет путешественника: `http://localhost:3000/guest`.
