## 1. ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ И ПЕРВОПРИЧИНЫ

1. **Ошибка сервера [400] при нажатии кнопки сохранения эталона:**
   - Пользователь столкнулся с ошибкой: `{"success":false,"error":"Лист \"🏠 Главная витрина\" пуст или содержит только шапку. Невозможно сформировать эталон."}`.
   - Первопричина: эндпоинт `pages/api/admin/save-master-seed.js` пытался запросить строки таблицы через Google Service Account JWT. Из-за отсутствия или невалидной сигнатуры ключа Google Sheets API в среде Vercel Lambda метод возвращал пустой массив, что приводило к ошибке 400.
   - Кроме того, функция `saveMasterSeedInteractive` в `Code.js` отправляла запрос на `/api/admin/save-master-seed` с пустым телом, не передавая уже собранные в таблице данные `livePayload`.

2. **Отсутствие авто-синхронизации при внесении правок в таблицу:**
   - При редактировании ячеек данные не передавались на сайт автоматически.
   - Первопричина: для автоматической отправки внешних HTTP-запросов из Google Apps Script требуется инсталлируемый триггер `onEdit`, которому пользователь должен явно выдать разрешение один раз через меню. Если триггер не был зарегистрирован или содержал устаревшие права, авто-синхронизация не срабатывала. Также отсутствовала визуальная индикация передачи правок.

---

## 2. СИСТЕМНЫЕ ИСПРАВЛЕНИЯ

1. **Серверный эндпоинт pages/api/admin/save-master-seed.js:**
   - Добавлена прямая поддержка пакета данных `livePayload` от Google Apps Script: 100% независимость от ключей сервисного аккаунта Google Cloud.
   - При наличии `livePayload` все 14 листов извлекаются напрямую из тела запроса.
   - Добавлена авторизация по секретному токену безопасности `REVALIDATE_SECRET_TOKEN`.
   - Запись файлов `content.json` и `masterSeedContent.js` защищена блоками try-catch для безопасной работы в read-only среде Vercel Lambda.
   - Добавлено сохранение в `/tmp/villa_live_content.json` для межконтейнерного обмена кэшем.
   - Добавлена прямая ревалидация статических страниц Next.js ISR для всех локалей `['/', '/ru', '/en', '/tr']`.

2. **Монолит Google Apps Script Code.js:**
   - Функция `saveMasterSeedInteractive`: теперь собирает полный снимок всех 14 листов через `collectAllSheetsPayload_` и передает его в теле POST-запроса вместе с секретным токеном.
   - Функция `setupAutoSyncTrigger`: теперь удаляет старые триггеры `onSheetEditTrigger` перед установкой нового, гарантируя чистое обновление прав доступа и информируя пользователя.
   - Функция `onSheetEditTrigger`: добавлен всплывающий тост в правом нижнем углу таблицы для мгновенной обратной связи владельцу о начале авто-синхронизации.

---

## 3. РЕЗУЛЬТАТ ВЕРИФИКАЦИИ

- Ошибка 400 полностью устранена: сервер принимает полный пакет данных `livePayload` и фиксирует эталон без обращения к сторонним API.
- Авто-синхронизация активируется в 1 клик через меню `🔄 2. Включить авто-синхронизацию правок таблицы с сайтом`.
- 100% соответствие всем директивам Единственного Законодательного Свода правил GEMINI.md.
