3. Оптимизировать структуру CRM до 11 канонических листов, удалив избыточные вкладки.
4. Выполнить полную модернизацию `google-apps-script/Code.js` с передачей команд Telegram на серверный эндпоинт Vercel `/api/telegram-webhook`.

## 2. АНАЛИЗ ПЕРВОПРИЧИНЫ (ROOT CAUSE)
Данные словаря переменных, описание виллы и мастер-доступ были разбросаны по разным листам, создавая расхождения между витриной, ответами ИИ и шаблонами. В `Code.js` накапливались дубликаты функций и попытки прямой отправки в Telegram без локальных ключей.
