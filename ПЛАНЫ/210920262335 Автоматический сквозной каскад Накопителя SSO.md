## 2. РЕАЛИЗОВАННЫЕ МЕХАНИЗМЫ

### 2.1. Автозапуск при открытии каталога в VS Code [runOn: folderOpen]
В файле `.vscode/tasks.json` корневой рабочей области сконфигурирована автозапускаемая задача:
- `"runOptions": { "runOn": "folderOpen" }`
- `"presentation": { "reveal": "silent", "panel": "shared", "clear": false }`
Задача без всплывающих окон и модальных запросов активирует `apply_settings.ps1` сразу при открытии папки проекта пользователем в VS Code.

### 2.2. Обязательный предварительный Шаг 0.0 во всех жизненных скриптах
Каждый ключевой сценарий управления жизненным циклом проекта перед выполнением своих основных функций запускает `apply_settings.ps1`:
1. `create_project_backup.ps1` - перед созданием локального и корневого бэкапов.
2. `push_project_to_github.ps1` - перед проверкой git-дерева и отправкой в ветки GitHub.
3. `sanitize_git_tree.ps1` - перед санитизацией и стейджингом изменений.

### 2.3. Защита кэша Git и актуализация .gitignore
- В корневой `.gitignore` добавлена директива исключения версий `СОХР_ПРОЕКТЫ/` и `**/СОХР_ПРОЕКТЫ/`.
- В сценарии `push_project_to_github.ps1` и `sanitize_git_tree.ps1` добавлена команда `git rm -r --cached --ignore-unmatch "СОХР_ПРОЕКТЫ" 2>$null`.

### 2.4. Фиксация Правила 6.5 в законодательной базе проекта
- В `GEMINI.md` [корень, Накопитель, Запускатор перенос, все 3 проекта] внесен пункт 6.5.
- В `AGENTS.md` добавлена краткая ссылка-регламент на пункт 6.5.
