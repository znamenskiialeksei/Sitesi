## 2. Анализ выявленных проблем и первопричины
1. **Переключатели Вкл / Выкл на листах Услуг и Гидов не влияли на витрину:**
   - На листах `🛎️ Дополнительные услуги` [колонка M] и `🗺️ Видео-путеводители` [колонка S] переключатель не учитывался парсером `utils/liveContentSync.js`. Все элементы безусловно попадали на сайт.
   - **Первопричина:** В парсерах `parseProducts` и `parseCourses` отсутствовала проверка флага доступности строки `r[12]` и `r[18]`.
2. **Письма с кодом верификации не отправлялись гостю:**
   - При регистрации или бронировании гость не получал 4-значный проверочный код на email.
   - **Первопричина:** В скрипте `google-apps-script/Code.js` объявление `function doPost(e)` дублировалось в середине и в конце файла. Второе объявление переопределяло первое и не содержало обработчика `send_verification_email`. Кроме того, тестовые заглушки маскировали отправку.
3. **Отсутствие верификации для прямого обращения хозяину [ContactHostModal]:**
   - Гость мог отправить сообщение без подтверждения контакта, что засоряло базу анонимными обращениями.
4. **Неверифицированные гости имели доступ к оформлению заявок и чатам:**
   - Отсутствовал единый серверный шлюз проверки подтверждения перед фиксацией броней.
5. **Сетевые сбои Канала 1 при обращении к Google Sheets:**
   - При квотах Google API или задержках сети сервер падал с HTTP 500 вместо прозрачного переключения на резервные Каналы 2 и 3.
6. **Перегруженность и дублирование в меню Google Таблицы:**
   - Меню содержали хаотичные пункты со скобками и тире. Отсутствовало централизованное системное меню экосистемы.
7. **Восстановление листов из скрипта стирало живые данные:**
   - Требовалось восстановление из `masterSeedContent.js` через Cloud API и облачные слепки Google Drive с хранением 10 версий.
8. **Отсутствие фиксации базы в GitHub:**
   - Не было инструмента прямого коммита `masterSeedContent.js` в репозиторий через GitHub REST API и запуска `git pull` в VS Code.

## 3. Программа реализации
1. **Коррекция парсера витрины `utils/liveContentSync.js`:**
   - Внедрение фильтрации по колонкам M и S со статусом Вкл/Выкл.
2. **Ликвидация дублирования и объединение шлюза в `Code.js`:**
   - Создание монолитного роутера `doPost` и `doGet` с обработкой `send_verification_email`, `contact_host`, `send_chat_message`, `save_settings`, `ping`.
   - Полное исключение демонстрационных режимов: только боевая отправка через `MailApp.sendEmail`.
3. **Обязательная верификация для ContactHostModal:**
   - Интеграция `VerificationModal` в `ContactHostModal.js` с вызовом `handleRequestVerification`.
4. **Серверный заслон в `pages/api/booking.js`:**
   - Блокировка действий без флага подтверждения в кэше с кодом HTTP 403.
5. **Отказоустойчивый три-канал failover:**
   - Канал 1 [Sheets API] -> Канал 2 [Apps Script Webhook] -> Канал 3 [Кэш /tmp].
6. **Централизация Меню 5 в `Code.js`:**
   - Формирование 14 стандартизированных команд без скобок и без длинного тире.
7. **Двухрежимное восстановление листов:**
   - On-Demand Cloud API Seed Pull из `masterSeedContent.js` + Облачный архив Google Drive на 10 слепков.
8. **Авто-сохранение masterSeed:**
   - Ручная команда 5.2 + авто-вызов при публикации и редактировании таблицы.
9. **GitHub REST API коммит и Git Pull:**
   - Прямой коммит `masterSeedContent.js` в ветки `v1-airbnb` и `main` + Задача 26 `📥 Git Pull` в `.vscode/tasks.json`.
10. **Безопасное автоформатирование:**
    - Форматирование исключительно стилей без изменения содержимого ячеек.
11. **Выпуск Редакции №6 архитектуры учета гостей:**
    - 11 колонок в листе `ACCOUNTS`, триггер повторной верификации и статус аккаунта.
