# ПЛАН: Комплексная ликвидация мерцания чата хозяина и снятие ограничения строк заголовков каталога

## 1. Метаданные плана
- Дата и время: 22.09.2026 23:25
- Статус: Успешно реализовано
- Приоритет: Критический
- Проект: villa-turaman-airbnb-platform, villa-turaman-variant2-classic, villa-turaman-platform

## 2. Суть задачи
1. Устранение мерцания, периодического исчезновения и появления чатов в панели хозяина, а также сброса выбранного диалога на первый в списке [выбрасывания из чата].
2. Снятие ограничения сокращения названий товаров и авторских видеопутеводителей в карточках витрины: расширение отображения заголовков до двух строк без усечения.
3. Полная ликвидация скрытых записей в Google Sheets при периодическом опросе master_get_chats во всех смежных вариантах монорепозитория.

## 3. Выполненные инженерные изменения

### Серверный уровень [pages/api/booking.js]
- Внедрен двухуровневый SWR-кэш для master_get_chats:
  - Проверка серверного кэша при повторных запросах чаще раза в 3.5 секунды;
  - Сохранение снимка при успешных ответах Google API;
  - Возврат данных из кэша вместо пустого массива chats: [] при любых ошибках Google Sheets API [429 Quota, 503 Backend Error, Network Timeout];
  - Инвалидация кэша master_all_chats_swr_cache при отправке нового сообщения гостем или хозяином.

### Кабинет хозяина [pages/host/index.js]
- Мгновенная инициализация chats и selectedChatSheet из localStorage [villa_host_master_chats_cache, villa_host_selected_sheet] для предотвращения пустого белого экрана при загрузке.
- Защита от наложения параллельных сетевых запросов через isFetchingChatsRef.
- Неразрушающее дифференциальное обновление: обновление стейта React выполняется только при непустом массиве и наличии реальных изменений в структуре данных [JSON diff], что гарантирует стабильность ссылок и исключает паразитный ре-рендеринг.
- Проброс onSelectChat в HostInbox для непрерывного отслеживания выбранного чата на уровне страницы.

### Компонент чата хозяина [components/HostCabinet/HostInbox.js]
- Железобетонная фиксация выбранного чата [Sticky Selection] через localStorage и useMemo: чат надежно удерживается и восстанавливается даже при фоновом опросе и повторном монтировании.
- Умная заморозка автоскролла: проверка счетчика сообщений prevMsgCountRef предотвращает дергание экрана вниз во время фонового опроса. Скролл срабатывает только при реальном поступлении новых сообщений или отправке ответа хозяином.
- Сохранение выбранного листа в localStorage при клике на карточку контакта.

### Карточки товаров и видеогидов [components/CatalogSection.js]
- Замена класса line-clamp-1 на line-clamp-2 min-h-[2.75rem] leading-snug в секциях консьерж-сервиса и авторских видео-путеводителей. Заголовки отображаются до двух полных строк, сохраняя идеальное выравнивание карточек.

### Синхронизация вариантов [variant2-classic и platform]
- Из обработчиков master_get_chats окончательно удален вызов await ensureSystemSheets[], устранявший лимит на запись в Google Sheets.
- В pages/index.js добавлена проверка Array.isArray[data.chats] && data.chats.length > 0 перед вызовом setMasterAllChats.
