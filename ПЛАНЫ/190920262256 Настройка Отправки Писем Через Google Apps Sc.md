# УТВЕРЖДЕННЫЙ ПЛАН : Настройка Отправки Писем Через Google Apps Script Gmail Relay и Telegram

## 1. Цель и контекст реализации
- Настройка отправки одноразовых проверочных кодов OTP гостям виллы через бесплатный Google Apps Script Gmail Relay без сторонних сервисов.
- Мгновенное дублирование проверочных кодов и заявок владельцу виллы в Telegram.
- Внедрение интерактивной поддержки тестового режима в модальном окне верификации для бесшовного тестирования при отсутствии внешних ключей.

---

## 2. Архитектура решения

### Блок 1 : Расширение Google Apps Script : google-apps-script/Code.js
- Реализация веб-обработчика doPost для приема запросов action === 'send_verification_email'.
- Отправка стилизованного HTML-письма с кодом через нативный MailApp.sendEmail учетной записи Google.
- Добавление интерактивного пункта меню в таблицу Google для копирования адреса веб-приложения.

### Блок 2 : Почтовый модуль : utils/mailer.js
- Поддержка шлюза GOOGLE_APPS_SCRIPT_URL : POST-запрос к веб-приложению Google Apps Script.
- Отправка уведомления в Telegram владельца через TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID.
- Возврат подробного статуса отправки : dev_local, apps_script, telegram.

### Блок 3 : Серверный контроллер : pages/api/booking.js
- В action === 'send_verification_code' возврат флагов isDevMode, devCode, telegramSent.

### Блок 4 : Интерфейс гостя : components/Modals/VerificationModal.js
- Отображение информационного бейджа при отсутствии шлюза с кнопкой быстрой подстановки кода.
- Индикация каналов отправки : Telegram, Email.

### Блок 5 : Шаблоны конфигурации : .env.local и .env.local.example
- Создание файлов конфигурации с русскими инструкциями по заполнению токенов Telegram и URL Google Apps Script.
