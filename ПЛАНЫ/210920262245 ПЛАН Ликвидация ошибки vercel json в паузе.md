## 1. ЦЕЛЬ И ЗАДАЧИ ЭТАПА
1. Устранить ошибку сборщика Vercel: `Build Failed: Invalid vercel.json file provided` при включении режима обслуживания `pause_site.ps1`.
2. Перейти на современный формат статической отдачи заглушки без устаревших параметров `version: 2` и `builds`.
3. Обеспечить 100% отдачу кода HTTP 503 и страницы `maintenance.html`.

---

## 2. АНАЛИЗ ПЕРВОПРИЧИНЫ (ROOT CAUSE)
В `pause_site.ps1` генерировался `vercel.json` по устаревшему стандарту Vercel v2 со свойствами `"version": 2` и `"builds"`, которые блокируются валидатором Vercel в проектах с фреймворком Next.js.

---

## 3. ПОШАГОВЫЙ ПЛАН ИЗМЕНЕНИЙ
1. В `pause_site.ps1` внедрить современный стандарт: `"framework": null`, `"buildCommand": null`, `"outputDirectory": "."`, `"cleanUrls": true`.
2. Настроить секцию `rewrites` на `/maintenance.html` и заголовки `Retry-After: 3600`.
3. Копировать заглушку в корень `index.html` и `public/maintenance.html`.
