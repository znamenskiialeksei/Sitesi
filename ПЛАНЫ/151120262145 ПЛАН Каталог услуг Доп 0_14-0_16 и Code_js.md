### 1.1. Первопричина сбоя [Root Cause Analysis]
При изучении исходного кода [pages/index.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/pages/index.js#L161-L166), [CatalogSection.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/components/CatalogSection.js#L138-L154) и [PresentationModal.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/components/Modals/PresentationModal.js#L17-L23) установлена точная причина падения:
1. В [pages/index.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/pages/index.js#L162) на строке 162 объявлено состояние выбранного элемента:
   ```javascript
   const [selectedPresentation, setSelectedPresentation] = useState(null);
   ```
   однако парное состояние типа презентации (`selectedPresentationType` и `setSelectedPresentationType`) **не было объявлено** в компоненте `HomeListing`.
2. При этом на строках 953–956 [pages/index.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/pages/index.js#L953-L956) в `CatalogSection` передается колбэк:
   ```javascript
   onSelectPresentation={(item, type) => {
     setSelectedPresentation(item);
     setSelectedPresentationType(type);
   }}
   ```
   а на строке 1047 [pages/index.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/pages/index.js#L1044-L1048) рендерится:
   ```javascript
   <PresentationModal
     item={selectedPresentation}
     type={selectedPresentationType}
   ```
3. В [CatalogSection.js](file:///c:/Новый%20сайт%20вилла%2015112026/1%20Вилла%20Сайт%20ГлобПрав%20изм%20осн%20правил%2015062026/villa-turaman-airbnb-platform/components/CatalogSection.js#L298-L320) и кнопка **«Подробнее об услуге»** (строка 299), и кнопка **«Заказать»** (строка 318 через `handleBuy` на строке 152, когда пользователь авторизован и отметил согласия) вызывают `onSelectPresentation(item, type)`. В момент вызова браузер мгновенно выбрасывает `ReferenceError: setSelectedPresentationType is not defined`, что приводит к экрану `Application error: a client-side exception has occurred`.

### 2.2. Ошибка размерности массива `accRows` при инициализации Листа 4 `ACCESS` [строки 1821–1831 `Code.js`]
