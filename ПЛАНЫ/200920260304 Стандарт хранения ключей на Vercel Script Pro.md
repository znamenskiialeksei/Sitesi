   - **Уровень 2:** Защищенное хранилище Google Apps Script :Script Properties: для обратных вызовов и триггеров из таблицы;
   - **Уровень 3:** Локальный конфигуратор .env.local для изолированной разработки в VS Code.
2. Создать защищенный диагностический серверный эндпоинт `/api/system-status` для проверки доступности ключей на Vercel без риска утечки их значений.
3. Добавить в меню Google Apps Script пункт `🌐 Проверить статус ключей на Vercel: https://vercel.com/` для интерактивной проверки здоровья облачной конфигурации прямо из таблицы.
4. Синхронизировать законодательные своды и технические адаптеры: `GEMINI.md`, `AGENTS.md`, `СВОД_СУТИ_И_РЕГЛАМЕНТОВ_НАКОПИТЕЛЯ.md`.

## 2. Реализованные изменения в кодовой базе

### 2.1. Серверный диагностический эндпоинт Next.js
* Создан файл `pages/api/system-status.js`:
  - Проверяет наличие ключей в `process.env`:
    - `GOOGLE_SPREADSHEET_ID`
    - `GOOGLE_CHATS_SPREADSHEET_ID`
    - `GOOGLE_CLIENT_EMAIL`
    - `GOOGLE_PRIVATE_KEY`
    - `TELEGRAM_BOT_TOKEN`
    - `TELEGRAM_CHAT_ID`
    - `REVALIDATE_SECRET_TOKEN`
    - `KV_DATABASE`
  - Возвращает структурированный JSON со статусом `ok: true/false` для каждого ключа, общим вердиктом и безопасными подсказками по настройке на https://vercel.com/. Не раскрывает значения секретов!

### 2.2. Google Apps Script: Code.js и TelegramBot.js
* Добавлен пункт меню: `🌐 Проверить статус ключей на Vercel: https://vercel.com/` в меню `🤖 Telegram Бот` и меню `🏡 Villa Turaman Suite`.
* Реализована интерактивная функция `checkVercelEnvStatusInteractive()`:
  - Выполняет HTTP-запрос к `[SITE_URL]/api/system-status`;
  - Анализирует статус каждого серверного ключа на Vercel;
  - Выводит наглядный модальный отчет со значками ✅ и ⚠️;
  - Дает четкую пошаговую инструкцию по добавлению недостающих ключей в панели `https://vercel.com/` в разделе `Settings ➔ Environment Variables`.
* Обновлены интерактивные диалоги настройки `setupTelegramPropertiesInteractive()` и `setupScriptPropertiesInteractive()` с разъяснением возможности централизованного размещения ключей на Vercel.
