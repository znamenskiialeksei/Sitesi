## 1. Разбор Первопричины Сбоя Сборки Vercel

### Ошибка компилятора SWC / Next.js
```
15:58:56.274 Error:
15:58:56.274   x the name `obsoleteEnglishNames` is defined multiple times
15:58:56.275      ,-[/vercel/path0/pages/api/admin/restore-sheets.js:46:1]
15:58:56.279   49 |     const obsoleteEnglishNames = [ ... ]
15:58:56.280      :           ^^^^^^^^^^|^^^^^^^^^
15:58:56.280      :                     `-- previous definition of `obsoleteEnglishNames` here
...
15:58:56.280   119 |     const obsoleteEnglishNames = [ ... ]
```

### Первопричина:
В файле `pages/api/admin/restore-sheets.js` переменные `obsoleteEnglishNames` и `deleteOldRequests` были объявлены через `const` дважды в одной области видимости функции `handler`:
- Первое объявление на строке 49: полный актуальный список из 15 устаревших англоязычных алиасов;
- Второе объявление на строке 119: старый усеченный дублирующий блок из 6 элементов.

По правилам JavaScript повторное объявление переменной через `const` в одной области видимости является фатальной синтаксической ошибкой, что привело к аварийной остановке сборки `npm run build` со статусом `exit code 1`.

## 2. Разбор Проблем Смарт-Менеджера в Google Apps Script

1. **Избыточность и путаница из 10 дублирующих пресетов:**
   - Пресеты дублируют друг друга: «Центр бронирований» vs «Фокус бронирований»; «Публичная витрина» vs «Редактор витрины»; «CRM» vs «Системные справочники» vs «Каталог & Продажи».
2. **Скрытие листов как концепция мешает работе:**
   - Всего в таблице 15 листов. Когда смарт-менеджер скрывает 10-12 листов, внизу экрана пропадают вкладки, таблица тормозит при многократных вызовах `hideSheet[]`, а пользователь теряет контекст.
3. **Отсутствие быстрой навигации:**
   - Вместо того чтобы просто сделать активным нужный лист в 1 клик без скрытия других, старый менеджер принудительно прятал все соседние вкладки.
