# ИНЖЕНЕРНЫЙ ПЛАН: Устранение ошибки синхронизации шаблонов в scripts/sync-content.js и utils/liveContentSync.js

> **Идентификатор плана:** `TAG: VILLA-SYNC-TEMPLATES-FIX-270920260126`  
> **Основание:** Запрос пользователя при выполнении задачи VS Code «npm run sync-content» с ошибкой `TypeError: content.templates[r[0]].push is not a function`.  
> **Соответствие директивам:** GEMINI.md [Блок 0, Блок I, Блок VIII], AGENTS.md. Zero-Terminal & Zero-Popup Policy [Правило 1.1], Zero-Brackets & Zero-Emdash Policy [Правило 2.7], Clickable File Links [Правило 1.6].

---

## 1. СУТЬ И СИСТЕМНЫЙ АНАЛИЗ ПЕРВОПРИЧИНЫ [ROOT CAUSE]

### Симптом сбоя:
При запуске задачи `npm run sync-content` терминал возвращает ошибку:
```
Синхронизация контента [Главная, О вилле, Юридический блок, Шаблоны]...
Ошибка синхронизации контента: content.templates[r[0]].push is not a function
Локальный кэш utils/content.json сохранен без изменений.
```

### Первопричина:
1. В каноническом эталоне SSOT [utils/content.json](file:///c:/1%20Вилла%20Сайт%20ГлобПрав%20260920261646/villa-turaman-airbnb-platform/utils/content.json#L2663) и генераторах [scripts/save-master-seed.js](file:///c:/1%20Вилла%20Сайт%20ГлобПрав%20260920261646/villa-turaman-airbnb-platform/scripts/save-master-seed.js#L382-L390) и [pages/api/admin/save-master-seed.js](file:///c:/1%20Вилла%20Сайт%20ГлобПрав%20260920261646/villa-turaman-airbnb-platform/pages/api/admin/save-master-seed.js#L390-L399) секция `templates` представляет собой **ассоциативный объект ключ-значение**:
   ```json
   "templates": {
     "1.1_discount_10": {
       "title": { "ru": "...", "en": "...", "tr": "..." },
       "text": { "ru": "...", "en": "...", "tr": "..." }
     }
   }
   ```
2. Однако в [scripts/sync-content.js](file:///c:/1%20Вилла%20Сайт%20ГлобПрав%20260920261646/villa-turaman-airbnb-platform/scripts/sync-content.js#L244-L262) на строках 244-262 ошибочно выполнялась попытка трактовать `content.templates[r[0]]` как массив:
   ```javascript
   if (!content.templates[r[0]]) content.templates[r[0]] = [];
   content.templates[r[0]].push({ ... });
   ```
   Так как `content.templates` инициализируется из `existingContent.templates` [где значения уже являются объектами `{ title, text }`], условие `!content.templates[r[0]]` не срабатывает, и вызов `.push[...]` на объекте выбрасывает `TypeError: content.templates[r[0]].push is not a function`.
3. Аналогичный уязвимый фрагмент содержится в [utils/liveContentSync.js](file:///c:/1%20Вилла%20Сайт%20ГлобПрав%20260920261646/villa-turaman-airbnb-platform/utils/liveContentSync.js#L500-L518).

## 2. ПОШАГОВЫЙ ПЛАН РЕАЛИЗАЦИИ

### Шаг 1: Исправление парсинга шаблонов в `scripts/sync-content.js`
- Привести наполнение `content.templates[id]` к канонической плоской структуре `{ title: { ru, en, tr }, text: { ru, en, tr } }` с безопасным санированием ячеек через `sanitizeText` и сохранением фоллбэков из `existingContent.templates?.[id]`.
- Обновить двухзаписную шапку файла:
  * Предыдущая редакция: `TAG: VILLA-HOST-WIDGET-CLEAN-270920260115`
  * Актуальная редакция: `TAG: VILLA-SYNC-TEMPLATES-FIX-270920260126`

### Шаг 2: Системная синхронизация в `utils/liveContentSync.js`
- В функции `processRawRowsToContent` на строках 500-518 заменить ошибочный `.push` на ассоциативную запись `content.templates[id] = { title, text }`, обеспечив полную совместимость со структурой `content.json`.
- Обновить двухзаписную шапку файла с тегом `TAG: VILLA-SYNC-TEMPLATES-FIX-270920260126`.

### Шаг 3: Верификация и фиксация в Хронологии проекта
- Зафиксировать исправление в `CHAT_CODE_FIXES_CHRONOLOGY.txt` в корне проекта и в папке `Глобальные настройки проекта [накопитель]` под Записью #108.
- Подготовить отчет пользователю для повторного запуска задачи `npm run sync-content`.
