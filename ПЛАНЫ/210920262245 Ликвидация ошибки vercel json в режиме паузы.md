# ПЛАН: Ликвидация ошибки Vercel [Invalid vercel.json file provided] и переход на современный стандарт режима обслуживания Vercel Pause [Запись #94]

## 1. Описание проблемы и первопричина

### Проблема:
При запуске режима обслуживания `pause_site.ps1` сборка Vercel на ветке `v1-airbnb` завершалась сбоем:
`Build Failed: Invalid vercel.json file provided`

### Первопричина:
Использование устаревшего стандарта Vercel v2 со свойствами `"version": 2` и `"builds"`, которые блокируются валидатором Vercel в проектах на Next.js.

---

## 2. Реализованное системное решение

1. **Современный формат конфигурации Vercel**:
   - `"framework": null`
   - `"buildCommand": null`
   - `"outputDirectory": "."`
   - `"cleanUrls": true`
   - `"rewrites"` для направления всех запросов на `maintenance.html`
   - `"headers"` с директивами `Cache-Control: no-store` и `Retry-After: 3600`
2. **Отказоустойчивость**:
   - Копирование `maintenance.html` в корень `index.html` и в каталог `public/maintenance.html`.
3. **Чистый Git Subtree коммит**:
   - Формирование изолированного коммита и безопасная отправка в ветку `v1-airbnb` с ключом `--force`.
4. **Соблюдение регламентов**:
   - Соблюдены стандарты UTF-8 BOM, Zero-Terminal [Правило 1.1], Zero-Brackets & Zero-Emdash [Правило 2.7] и непрерывной хронологии [Правило 6.4].
