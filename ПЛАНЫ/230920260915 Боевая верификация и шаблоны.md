# Боевая верификация без отладки и смарт-шаблоны

## Цель реализации
1. Перевод системы авторизации и подтверждения контактов в 100% боевой режим: исключение отображения отладочного кода в окне верификации и ликвидация утечки devCode в ответах API.
2. Реализация заметной кнопки изменения контакта [email / телефон] гостя с возможностью отмены и автоматическим обновлением данных в профиле AuthContext.
3. Обеспечение надежной отправки писем через Google Apps Script Gmail Relay под аккаунтом villaturaman@gmail.com с обходом ограничений 302 редиректа Node.js fetch.
4. Внедрение панели быстрого выбора смарт-шаблонов непосредственно над полем ввода сообщения в кабинете хозяина с фильтрацией по стадиям и языкам.
5. Интеллектуальное сопоставление стадий stageId для шаблонов из живой таблицы Google Sheets.

## Измененные компоненты
- `components/Modals/VerificationModal.js`: удален блок devCode, добавлена кнопка [ ✏️ Изменить ], форма редактирования с отменой и синхронизация с useAuth.
- `pages/api/booking.js`: удалены поля devCode и isDevMode из ответа send_otp.
- `utils/mailer.js`: переведен запрос к Google Apps Script на первичный GET с query-параметрами, зафиксирован isDevMode: false.
- `components/HostCabinet/HostInbox.js`: внедрена быстрая панель смарт-шаблонов прямо над textarea ввода сообщения с переключателем языков [RU, EN, TR].
- `utils/aiKnowledgeBase.js`: добавлен автоматический расчет stageId по префиксу идентификатора шаблона.
- `villa-turaman-variant2-classic/google-apps-script/Code.js` и `villa-turaman-platform/google-apps-script/Code.js`: синхронизирован обработчик handleWebhookRequest_.

## Верификация
- В окне ввода проверочного кода отсутствует блок отладки.
- Поле редактирования контакта раскрывается по клику на [ Изменить ], сохраняет новый адрес и отправляет код.
- Кнопка [ Умные шаблоны [14] ] над полем ввода чата хозяина раскрывает список шаблонов с подставленными данными гостя и позволяет вставить текст в 1 клик.
- Правила Rule 1.1 [Zero-Terminal] и Rule 2.7 [Zero-Brackets & Zero-Emdash] соблюдены на 100%.
