# Комплексный план модернизации восстановления Google Sheets

## 1. Анализ первопричин сбоев

### А. Ошибка в `Code.js` (Google Apps Script):
`TypeError: Cannot read properties of undefined (reading 'length')`
- **Первопричина:** В объекте `VILLA_SHEETS_CONFIG` у листов не определено свойство `headers`. На строке 3290 вызов `var maxCols = cfg.headers.length;` аварийно падает, а функция `styleSheetHeader_` на строке 3236 не формирует шапку.

### Б. Ошибка в `scripts/restore-sheets.js` (`npm run restore-sheets`):
`Invalid data[6]: Requested writing within range ['🔑 Управление доступом'!A2:G6], but tried writing to column [H]`
- **Первопричина:**
  1. В `restore-sheets.js` диапазоны записи для `ACCESS` и `ACCOUNTS` были жестко захардкожены до колонки `G` (`A2:G`), что соответствует только 7 колонкам.
  2. Массив `MASTER_ACCESS_ROWS` содержит 8 колонок (`A:H`), а обновленный `MASTER_ACCOUNTS_ROWS` содержит 13 колонок (`A:M`). Google Sheets API при несовпадении количества колонок в данных и границах диапазона возвращает ошибку валидации.
  3. В скрипте отсутствовала обработка листа 15 `GUIDE_ACCESS` (`MASTER_GUIDE_ACCESS_ROWS`), а заголовок консоли устарел («11 канонических листов» вместо 15).

## 2. Предлагаемые системные решения

### Задача 1. Исправление `google-apps-script/Code.js`
1. **Канонические `headers` в `VILLA_SHEETS_CONFIG`:** Добавить полные массивы заголовков колонок для всех 15 листов в строгом соответствии с `sheetsRegistry.js`.
2. **Защитная инициализация и вычисление ширины:**
   - В функциях `restoreSheetsFromCloudApiInteractive` и `restoreFromDriveSnapshotFileId_`:
     ```javascript
     var headers = (cfg && cfg.headers && cfg.headers.length > 0) ? cfg.headers : null;
     if (headers) {
       styleSheetHeader_(sheet, headers, 1, cfg.minWidths);
     }
     var maxCols = (headers && headers.length > 0) ? headers.length : (dataRows[0] ? dataRows[0].length : 1);
     ```
   - Запись строго со строки 2 (`sheet.getRange(2, 1, rectRows.length, maxCols).setValues(rectRows)`).

### Задача 2. Исправление `scripts/restore-sheets.js`
1. **Динамический расчет диапазонов `getBoundingRange`:**
   Внедрить универсальный генератор буквенного диапазона A1 Notation:
   ```javascript
   function getColumnLetter(colIndex) {
     let temp, letter = '';
     while (colIndex > 0) {
       temp = (colIndex - 1) % 26;
       letter = String.fromCharCode(temp + 65) + letter;
       colIndex = Math.floor((colIndex - temp - 1) / 26);
     }
     return letter;
   }
   ```
2. **Безопасная нормализация и упаковка данных:**
   - Для `ACCESS`: расчет диапазона по фактической ширине `MASTER_ACCESS_ROWS` (колонки `A:H` или дополнение до 10 колонок `A:J`).
   - Для `ACCOUNTS`: запись всех 13 колонок `A2:M${MASTER_ACCOUNTS_ROWS.length + 1}`.
   - Для `GUIDES`: обеспечение сохранения колонки 19 (`S` - `Наличие`).
   - Добавление обработки 15-го листа `GUIDE_ACCESS` (`MASTER_GUIDE_ACCESS_ROWS`).
   - Обновление интерфейсных сообщений до актуального стандарта «15 канонических листов».
