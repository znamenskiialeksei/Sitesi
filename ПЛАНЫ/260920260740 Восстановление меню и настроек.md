# План: Восстановление функций меню и настроек экосистемы

## Цель и задачи
1. Фиксация в Глобальных правилах проекта Директивы 3.14: стандарт прямой доставки Duplex Push livePayload, нулевая зависимость от Google Cloud JWT, межконтейнерный кэш /tmp и сквозная ревалидация всех локалей ISR.
2. Ликвидация показа устаревшей редакции сайта на смартфонах и планшетах: синхронная ревалидация `['/', '/ru', '/en', '/tr']` и барьер против сброса кэша в браузере при `jwt_auth_error` или `local_fallback`.
3. Полное восстановление работоспособности всех 4 меню Google Apps Script `Code.js` и сопутствующих сервисов с переходом на канонический боевой домен `https://www.villaturaman.com`.

## Выполненные инженерные изменения

### 1. Клиентская витрина: pages/index.js
- Внедрен барьер в функции `fetchLiveContent`: если ответ API содержит признак `jwt_auth_error`, `local_fallback` или `fallback_on_error`, клиентский интерфейс не перезаписывает живые данные экрана.
- Исключен параметр `force=true` при регулярных клиентских опросах для предотвращения деградации кэша.

### 2. Серверный шлюз ревалидации: pages/api/revalidate.js
- Расширен список целевых путей ревалидации ISR: `['/', '/ru', '/en', '/tr']`.
- Обеспечено одновременное обновление страниц для всех языковых локалей на CDN Vercel Edge.

### 3. Межконтейнерная синхронизация: utils/liveContentSync.js
- Добавлено сохранение и чтение пакета `livePayload` из временного файла `/tmp/villa_live_content.json`.
- Новые серверные контейнеры Vercel Lambda при холодном старте получают актуальный снимок Google Таблицы без задержек.

### 4. Монолит Google Apps Script: Code.js
- `auditScriptIntegrityAndTokens`: перевод на `getEffectiveSiteUrl_()` и боевой домен.
- `getTelegramConfig_`: перевод проверки статуса на боевой домен.
- `showAiFullStatusModal`: перевод на боевой домен.
- `syncAiKnowledgeToVercel`: прямая доставка пакета всех 14 листов таблицы через `triggerRevalidateWebhook` без риска обнуления.
- `checkGeminiVercelStatusInteractive`: перевод на боевой домен.
- `testAiConciergeInteractive`: перевод на боевой домен.
- `saveMasterSeedInteractive`: перевод на боевой домен.
- `setupScriptPropertiesInteractive` и `setupDefaultScriptProperties`: установка значения по умолчанию `https://www.villaturaman.com`.

### 5. Глобальные правила проекта: GEMINI.md и AGENTS.md
- В Накопитель и корень репозитория добавлена Директива 3.14 [Duplex Push SSOT Policy].
- Оглавление документов синхронизировано.
