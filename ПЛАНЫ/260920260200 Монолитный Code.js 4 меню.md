# План реализации: Устранение сбоев в Code.js, создание 100% автономного монолитного скрипта Google Apps Script с 4 главными меню и исправление ошибок вызова функций

## 1. Выявленные проблемы и Первопричины

После детального аудита скрипта `villa-turaman-airbnb-platform/google-apps-script/Code.js` выявлены следующие фундаментальные первопричины, из-за которых скрипт не работал как надо в Google Apps Script:

### 1.1. Исчезновение Меню 2 [🤖 Telegram-бот] при установке Code.js в Google Apps Script
* **Первопричина:** В функции `onOpen` меню Telegram-бота вызывалось через вызов функции `registerTelegramBotMenu`, которая была объявлена в отдельном внешнем файле `TelegramBot.js`.
  При копировании только `Code.js` в Google Apps Script вызов приводил к `ReferenceError`, а пустой блок `catch` маскировал ошибку, и меню не отображалось.
* Вспомогательные функции Меню 2 [`getTelegramActiveSections_`, `toggleTelegramMenuSectionsInteractive`, шпаргалки `showVsCodeTaskGuide_*`, `sendVsCodeTasksSummaryToTelegram`] отсутствовали в `Code.js`.

### 1.2. Ошибка вызова необъявленной функции `findConfigSheet_` на строке 2393
* **Первопричина:** В функции банковского аудита `auditPendingBankPaymentsModal` был ошибочный вызов `findConfigSheet_['BOOKINGS']`. Канонический метод экосистемы: `findSheetByConfigKey[ss, 'BOOKINGS']`.

### 1.3. Рассинхронизация наименований 4 главных меню
* В паспорте проекта зафиксированы 4 канонических главных меню верхнего уровня:
  1. `🏡 1. Villa Turaman Suite`
  2. `🤖 2. Управление Telegram-ботом`
  3. `🧠 3. ИИ-Агент & Gemini`
  4. `💼 4. Секретарь • Юрист • Бухгалтер`
* В старом коде номера отсутствовали у меню 1 и меню 2.

---

## 2. Архитектурное решение

В соответствии с Правилом 1.2 [Total Root Cause Elimination Policy] и стандартом монолитных скриптов:

### 2.1. Превращение Code.js в 100% самодостаточный автономный монолит
1. Перенести функцию `registerTelegramBotMenu` непосредственно внутрь `Code.js`.
2. Перенести все сопутствующие функции Telegram-бота и карточек VS Code в `Code.js`:
   - `getTelegramActiveSections_` : считывание активных разделов из Script Properties;
   - `toggleTelegramMenuSectionsInteractive` : интерактивный конструктор 7 разделов меню;
   - 10 функций шпаргалок запуска `showVsCodeTaskGuide_*`;
   - `sendVsCodeTasksSummaryToTelegram`.
3. В результате пользователю достаточно скопировать один файл `Code.js` в редактор Google Apps Script.

### 2.2. Прямая регистрация 4 главных меню в onOpen
Зарегистрировать все 4 меню верхнего уровня строго и детерминированно:
- Меню 1: `🏡 1. Villa Turaman Suite`
- Меню 2: `🤖 2. Управление Telegram-ботом`
- Меню 3: `🧠 3. ИИ-Агент & Gemini`
- Меню 4: `💼 4. Секретарь • Юрист • Бухгалтер`

### 2.3. Исправление строки 2393 в Code.js
Заменить вызов на:
```javascript
var ss = SpreadsheetApp.getActiveSpreadsheet();
var sheet = findSheetByConfigKey(ss, 'BOOKINGS');
```

### 2.4. Фиксация концепции в Глобальные правила проекта
- Правило 3.13 в Блоке III: Монолитный стандарт Google Apps Script: Code.js как единый автономный скрипт экосистемы [Apps Script Monolith SSOT Policy]
- Правило 9.12 в Блоке IX: Запрет фрагментации Apps Script и скрытых зависимостей в onOpen
- Внесение в GEMINI.md и AGENTS.md в корне и в Накопителе.
