# План: Полное устранение сбоя обновления сайта при редактировании Google Таблицы и по кнопке меню

## 1. Описание проблемы и выявленные первопричины

Заказчик сообщил:
> *«ничего не обнавляется на сайте»*  
> *«сейчас не происходит обнавления сайта при внесении изменений в таблицу и по кнопке меню тоже»*

В ходе сквозного аудита всей цепочки передачи данных [Google CRM Таблица ➔ Apps Script Code.js ➔ Сеть/Vercel ➔ Next.js API /api/revalidate и /api/content ➔ Клиентский рендеринг] выявлены **7 критических первопричин**, из-за которых сайт не обновлялся:

1. **Блокировка вебхуков защитой Vercel [Deployment Protection / Vercel Authentication]:**  
   Целевой адрес `https://sitesi-git-v1-airbnb-znamenskiialekseis-projects.vercel.app` находится в режиме защищенного превью Vercel. При любых внешних запросах к `/api/revalidate` и `/api/content` Vercel выдает HTTP 307 перенаправление на страницу логина `https://vercel.com/login`. Запрос ревалидации не доходит до Next.js.
2. **Ложное сообщение об успешной публикации в `Code.js`:**  
   Функция `triggerRevalidateWebhook()` в `Code.js` проверяет только код `res.getResponseCode() === 200`. Так как Vercel при перенаправлении возвращает 200 для HTML-страницы логина, скрипт выводит пользователю ложный тост «Сайт успешно обновлен», хотя вебхук был перехвачен и не выполнен. Скрипт обязан валидировать JSON-ответ: `data.success === true && data.revalidated === true`.
3. **Недостижимость localhost из облака Google Apps Script:**  
   В `setupDefaultScriptProperties()` параметр `SITE_URL` по умолчанию выставлялся в `http://localhost:3000`. Облачный движок Google Apps Script физически не имеет доступа к локальному компьютеру разработчика по адресу `localhost:3000`. В `Code.js` необходим интеллектуальный каскад: чтение боевого URL из листа `SETTINGS` [параметр `vercel_url`], валидация и предупреждение пользователя.
4. **Спящий режим триггера авто-синхронизации правок таблицы:**  
   Простой триггер `onEdit(e)` в Google Apps Script по правилам безопасности Google не имеет прав на внешние сетевые вызовы `UrlFetchApp.fetch`. А триггер `onSheetEditTrigger(e)` требует явной установки через меню. Необходимо снабдить пользователя понятным индикатором статуса авто-синхронизации и прямой кнопкой гарантированной публикации.
5. **Блокировка обновления производных коллекций в `homeDerivedCollections.js`:**  
   Функции генерации структурированных коллекций [спальни, удобства, отзывы, спа-зона, безопасность] содержали проверку `if (!home.bedrooms || home.bedrooms.length === 0)`. Так как базовый каркас предзаполнялся из кэша, свежие строки из Google Таблицы [например, `bedroom_1`, `amenity_main_1`] игнорировались, и коллекции на сайте оставались старыми.
6. **Несоответствие колонок в скрипте синхронизации `scripts/sync-content.js`:**  
   Скрипт `sync-content.js` считывал лист `HOME` как 5-колоночный `A:E` [где колонка 0: ключ], в то время как канонический конструктор витрины является 8-колоночным `A:H` [где колонка 0: имя блока, колонка 1: ключ]. Это приводило к искажению локального кэша `content.json`.
7. **Отсутствие диагностического вывода источника данных на сайте:**  
   При возникновении сетевых задержек или обращении к резервному кэшу пользователь не видел, из какого источника отображаются данные: из живой Google Таблицы или из локального fallback-файла.

## 2. Предлагаемые изменения

Group files by component:

### Компонент 1: Google Apps Script [`google-apps-script/Code.js`]

#### [MODIFY] [Code.js](file:///c:/1%20Вилла%20Сайт%20—%20копия%20с%20Глобальными%20правилами%20проекта/villa-turaman-airbnb-platform/google-apps-script/Code.js)
1. **Валидация JSON в `triggerRevalidateWebhook()`:**  
   - Парсинг тела ответа через `JSON.parse(res.getContentText())`.
   - Проверка флагов `data.success === true && data.revalidated === true`.
   - Если сервер вернул HTML [например, страницу логина Vercel или ошибку Cloudflare], выводить четкое предупреждение: `⚠️ Vercel заблокировал запрос: отключите Vercel Authentication в настройках проекта на vercel.com`.
2. **Интеллектуальный выбор `siteUrl`:**  
   - Если `props.getProperty('SITE_URL')` не задан или равен `http://localhost:3000`, скрипт автоматически извлекает актуальный боевой адрес витрины из листа `SETTINGS` [категория `СИСТЕМА`, параметр `vercel_url`].
   - Если в Свойствах скрипта указан `localhost:3000`, скрипт информирует пользователя о невозможности вызова локального ПК из облака Google и предлагает переключить на рабочий URL Vercel.
3. **Обновление триггера `onSheetEditTrigger`:**  
   - Информативное уведомление об активности триггера в меню.
   - Синхронизация вызова ревалидации при редактировании любых витринных листов.
