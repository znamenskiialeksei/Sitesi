# VILLA TURAMAN — AIRBNB PLATFORM v2.0 🌟

> **Современная премиальная платформа бронирования виллы с разделением личного кабинета Путешественника (Guest Cabinet) и личного кабинета Хозяина (Host Cabinet), декомпозированной архитектурой и интеграцией с Google Sheets CRM.**

## 🛠 Устраненные проблемы и ключевые улучшения

1. **Регламент локали Google Sheets (Rule 2):**
   - Устранена критическая ошибка `#ERROR!` (*"Ошибка синтаксического анализа формулы"*).
   - Все программные формулы передаются в Google Sheets API со строгим каноническим синтаксисом США (с запятыми `,`), благодаря чему в русском интерфейсе Google Sheets они автоматически отображаются с точкой с запятой (`;`).
2. **Переход на метаданные ваучеров (RichText):**
   - Устранены уязвимые формулы `=HYPERLINK()`. Ссылки на ваучеры и вложения встраиваются чисто и безопасно.
3. **Строгое разделение личных кабинетов:**
   - Путешественник (`/guest`) видит свои поездки, статус 24h HOLD с таймером обратного отсчета, скачивает ваучер заселения, общается с хозяином в личном чате и изучает приобретенные видео-гиды.
   - Хозяин (`/host`) защищен двухфакторной аутентификацией Google Authenticator (TOTP), имеет доступ к управлению бронями (одобрение, спецпредложения, отмена), гибкому мульти-месячному календарю с переопределением цен, CRM-чату с массовой рассылкой и менеджеру каналов.
4. **Современные Toast-уведомления:**
   - Все устаревшие всплывающие окна браузера `alert()` заменены на элегантные асинхронные тосты `useToast()` с автоматическим скрытием.
