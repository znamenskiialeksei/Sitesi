## 3. Семантические теги для мгновенного поиска через `grep_search`

Для быстрого перехода к нужной логике без открытия файлов используйте поиск по стандартизированным меткам:

| Семантический тег | Где искать | Что находит |
| :--- | :--- | :--- |
| `// [КЛАСТЕР: ВИТРИНА]` | `utils/sheetsRegistry.js` | 6 листов публичной витрины |
| `// [КЛАСТЕР: CRM]` | `utils/sheetsRegistry.js` | 8 листов центра управления хозяина |
| `// [API: GOOGLE_SHEETS]` | `pages/api/` | Прямые взаимодействия с Google Sheets API |
| `// [AUTH: MASTER]` | `context/AuthContext.js` | Проверка прав владельца и сессии 2FA |
| `// [RULE: SEMICOLON]` | `init-google-sheets.js` | Формулы с точкой с запятой (`;`) |
| `// [RATE: TCMB]` | `pages/api/rates.js` | Официальные валютные курсы ЦБ Турции |
| `// [PRESET: VISIBILITY]` | `google-apps-script/Code.js` | 10 пресетов видимости смарт-менеджера |

## 4. Горячие клавиши VS Code для мгновенной навигации
- `Ctrl + P` — Быстрый переход к любому файлу по его имени (например, введите `sheetsReg` или `Code.js`).
- `Ctrl + Shift + O` — Быстрый поиск функции/символа внутри открытого файла.
- `Ctrl + Shift + F` — Глобальный поиск по проекту с учетом семантических меток выше.
- `Ctrl + Shift + B` — Мгновенный запуск сервера разработки Next.js.
